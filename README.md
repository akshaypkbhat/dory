# Dory

A personal work assistant for two people (you + partner). Text-based chat assistant with shared to-dos, priorities, and messaging, built on context you provide about your work, skills, and current projects.

## Stack

- React + Vite (frontend)
- Firebase (Auth + Firestore) for data and the two-user login

## Status

Early scaffold — chat UI, data model, and Firebase project setup still to come.
